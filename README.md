## 🚗 **Project Overview**

This repository serves as the full development portfolio for my Raspberry Pi Car 5 build.  
It includes:

- **Setup and configuration guides** for the Raspberry Pi Car 5 and Robot HAT controller
- **Module‑by‑module documentation**, including experiments, testing scripts, and results
- **Final project development**, lessons learned, and planned future improvements

The goal of this project is to demonstrate the complete lifecycle of building and 
programming a functional robot—from initial hardware setup, to movement and sensor testing, 
to more advanced features such as:

- **Camera streaming and control**
- **Ultrasonic distance sensing**
- **Autonomous steering logic**
- **Real‑time decision‑making**
